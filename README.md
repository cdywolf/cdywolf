## Featured Projects

### 🧭 llm-eval-mcp &nbsp; `AI Agents · MCP · Evaluation`
An evaluation platform for LLM agents, exposed both as an MCP server and a web API. It generates adversarial tasks, scores answers with an LLM acting as a judge, and tracks reliability over time. Built on a clean ports and adapters core, fully testable with no key and no network.
**Stack:** Python, MCP, FastAPI, SQLAlchemy, Docker, GitHub Actions
[![Repo](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/cdywolf/llm-eval-mcp) &nbsp; [![Demo](https://img.shields.io/badge/Live%20Demo-1f6feb?style=flat-square)]([DEMO_LINK])

### 🎓 Adaptive Learning Platform &nbsp; `RAG · LLM Application`
An education platform powered by a specialized LLM. It builds diagnostics, personalized learning paths, quizzes, and reports using tool calling, retrieval pipelines, and structured outputs.
**Stack:** Python, LangChain, GPT-4o, FastAPI, Streamlit, RAG
[![Repo](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github&logoColor=white)]([PROJECT_LINK]) &nbsp; [![Demo](https://img.shields.io/badge/Live%20Demo-1f6feb?style=flat-square)]([DEMO_LINK])

### 📄 Efficient Document AI with PEFT &nbsp; `Document AI · Model Compression`
Fine tuned a vision language model (Donut) for information extraction and benchmarked 16 parameter efficient configurations. Matched full fine tuning accuracy while training **0.57% of the parameters** on a model **4x smaller**, with large cuts in inference cost, GPU usage, and memory.
**Stack:** PyTorch, Hugging Face Transformers, LoRA / QLoRA, MLflow
[![Repo](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github&logoColor=white)]([PROJECT_LINK])

### 🔎 LLM Agent Cost Teardown &nbsp; `Evaluation · Observability`
Instrumented an autonomous web agent to break down cost per task by tokens and steps across five complexity levels. Showed that most tokens came from vision inputs rather than reasoning, and traced spend to steps and page density rather than abstract difficulty.
**Stack:** Python, token and latency instrumentation, failure analysis
[![Repo](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github&logoColor=white)]([PROJECT_LINK])

### 📈 Time Series Forecasting &nbsp; `Deep Learning · Forecasting`
Built an LSTM model for stock price forecasting with a full data processing pipeline and real time prediction dashboards for analytical decision support.
**Stack:** PyTorch, LSTM, pandas, Streamlit
[![Repo](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github&logoColor=white)]([PROJECT_LINK])
