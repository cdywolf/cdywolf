### `// recent work`

**Parameter efficient fine tuning for Donut** &nbsp;`OCR free document understanding`
Benchmarked **16 PEFT configurations** and matched full fine tuning accuracy while training **0.57% of the parameters** and shipping a model **4x smaller**.

**Adversarial evaluation suite for an open source LLM research agent** &nbsp;`in progress`
Sixty tasks across six failure categories, instrumented for sub queries, sources, token cost, and latency. Traced failures to **planning and retrieval rather than generation**, and found a single 24k token write call driving most of the bill.

### `// featured`

**[llm-eval-mcp](https://github.com/cdywolf/llm-eval-mcp)** &nbsp;`Python · MCP · FastAPI · Docker`
An evaluation platform for LLM agents, exposed both as an MCP server and a web API. It generates adversarial tasks, scores answers with an LLM acting as a judge, and tracks reliability over time. Built with a clean ports and adapters core, so the whole thing is testable with no key and no network.
